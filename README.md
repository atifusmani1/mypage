# Atif Usmani's personal website

A single-screen dark portfolio built with Next.js App Router, React 19,
TypeScript, and Tailwind CSS v4.

## Development

Run all commands from the **repository root** (`mypage/`). Node 22 is recommended.

```bash
npm ci
npm run dev          # http://localhost:3000
npm run lint
npm run typecheck    # after next dev or next build generates framework types
npm run build
npm start            # serve the production build at :3000
```

There is no separate backend and no required environment configuration. The old
`frontend/` and `backend/` projects have been removed. Stop an existing dev server
before starting another server on port 3000.

## Editing content

Edit **[`content/about.md`](content/about.md)** to change the portrait summary.
Use plain paragraphs separated by blank lines, without Markdown headings or
formatting. The server reads this file directly; refresh the page during
development and rebuild to update production content.

Résumé index rows and their detail-page bullets live in `src/data/site.ts`, condensed
from the supplied PDF. Email, GitHub, LinkedIn, and MTC Instagram destinations live
in `src/app/page.tsx` and `src/data/site.ts`. Add `video: { id, title }` to a detail
entry to embed its YouTube demo.

Photos for More Life live in `content/image-panes/photos/`. Add originals there, run
`npm run photos` to write upright 1600px JPEGs into `public/images/photos/`, then add
`{ src, title }` entries to `src/data/photos.ts`. Titles carry no dashes and rotate
around the cursor on hover. The script uses macOS Quick Look and `sips` to apply the
HEIC rotation that `sips` alone drops.
Search indexing remains disabled until publication is approved.

## Design and behavior

- One opening screen on desktop; readable vertical scrolling on phones.
- Name tucked into the top left as plain text, not a bar or navigation.
- On the first visit in a tab, a three-line typing sequence plays above the
  details: “Welcome!” above “Always Building.” above “Always Learning.” It types
  in one pass, then the page content drops in.
- The intro plays once per tab and is skipped entirely for reduced-motion
  preferences. Without JavaScript, the final page renders immediately.
- ASCII portrait at the top right, with the About summary and three text links beneath it.
- Education, Work, Leadership, Projects, and Research form a compact three-column
  index down the left: organization, role, and a few-word summary.
- All Work rows open `/work`: three black, shadowed logo tiles with gaps and outer
  margins, stacked on phones. Supplied PNG logos remain fully visible.
  Hover expands the cursor with a slowly rotating experience title. Selecting a
  pane opens its existing résumé details in a centered black dialog over blurred,
  dimmed panes. Outside click, Close, or Escape dismisses it; focus returns to the pane.
  Without JavaScript, pane links open the original static experience detail pages.
- Both Projects rows open `/projects`: two matching logo tiles with rotating
  cursor titles. Each opens a centered popup with its embedded demo and a brief
  description underneath. Closing unmounts the player, stopping playback.
  Videos start muted; reduced motion loads them paused. Without JavaScript,
  tiles link to the existing project detail pages.
- Both Research rows open `/research`: two matching logo tiles labeled BIAS Lab
  and Cell Universe Lab. Each opens a centered popup with the résumé summary and
  the supplied figures below it. Outside click, Close, or Escape dismisses it and
  focus returns to the tile. Without JavaScript, tiles open the existing research
  detail pages, which also show the figures. MTC UCI opens Instagram.
  Detail pages and every gallery have a plain “← Home” link. Education stays unlinked.
- “More Life” sits at the bottom left of the homepage and opens `/more-life`:
  three black photo tiles dealt from a freshly shuffled list each visit. One
  pane cross-fades every 1.2 seconds (3.6 seconds per pane). There are no
  captions or controls; the cursor carries the only visible title. Hovering a
  tile pauses the strip and expands the cursor with that photo's title. The
  rotation stops for reduced-motion preferences. Phones stack the tiles.
- Solar Shield and Parallax AI detail pages embed their demos with YouTube's
  privacy-enhanced player. Opening the page starts playback muted, since browsers
  block audible autoplay; the player controls unmute. Reduced motion loads the
  player paused, and a plain YouTube link is shown before hydration or without JS.
- On phones, each index entry stacks its three parts; nothing is clipped.
- Text is white; contact and résumé links have no underline and fade to
  thermal-colored text on hover/focus, with no background highlight. Keyboard
  focus keeps a visible outline.
- A white hollow-circle mouse cursor; native cursor on touch, reduced motion, and forced colors.
- Portrait hidden during typing; its existing glyph-sized image fragments fall
  into place with the résumé reveal, then settle into the static PNG. No looping;
  reduced motion and returning visits show the still immediately.
- No homepage header, nav bar, glass effect, or footer. The Work dialog has a
  native Close button; detail pages remain available as separate static routes.
- Visible keyboard focus and reduced-motion support.
- Original portrait references and compiled effect code stay in `docs/design/`,
  not `public/`. The supplied gallery photos live in `content/image-panes/photos/`;
  only their prepared JPEG copies are served from `public/images/photos/`. The
  portrait and bundled Work logos are served by the page.

The site adds no analytics, tracking, visitor data collection, terminal simulation,
or chat service. The Solar Shield and Parallax AI pages load YouTube's
privacy-enhanced player (also used in Projects popups), which contacts Google
and may set its own cookies.
Dependencies and lockfile describe only the active Next.js application.
